# 12 — Procure rank-5 Treasure keys safely

**What to build:** Reserve and obtain a key only for an exact reachable rank-5 Treasure on the selected safe branch, falling back to approved Treasure HP payment when procurement is impossible.

**Blocked by:** 03 — Project route-horizon safety and erosion recoverability; 09 — Resolve Event options into exact commitments; 11 — Execute Treasure payment without deadlock.

**Status:** ready-for-agent

- [ ] A known reachable rank-5 Treasure without a held key creates one branch-local mandatory procurement objective.
- [ ] The objective outranks nonterminal combat but never terminal Boss or route safety.
- [ ] A 150-Gold Event key and 200-Gold Shop key are recognized only from exact reachable content before that Treasure.
- [ ] Currency-paid key sources are preferred when reachable and affordable.
- [ ] If no permitted source is reachable or affordable, the plan continues to approved Treasure HP payment rather than pausing.
- [ ] An 80-percent-HP Event key is eligible only for the known rank-5 objective, no better currency source, and projected group survival.
- [ ] The Event's parameter 80 erosion key is treated as +80 points and requires no battle above 70 plus certain recovery before the next battle.
- [ ] A key is never bought speculatively for hidden or alternative-branch Treasure.
- [ ] A key is not reserved or spent for ordinary Code Offers, Gold, lower-rarity bags, or unrelated rewards.
- [ ] Commitments are cleared and recomputed after every authoritative resource or branch mutation.
- [ ] Tests cover both currency costs, both exceptional Event payments, unreachable sources, hidden Treasure, and HP fallback.
