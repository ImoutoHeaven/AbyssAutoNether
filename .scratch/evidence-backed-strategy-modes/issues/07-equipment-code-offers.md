# 07 — Select and replace Equipment-mode Code offers

**What to build:** Make each Equipment Code Offer improve the configured party's actual Boss combat portfolio, or safely reroll and decline it when no improvement exists.

**Blocked by:** 01 — Explicit strategy modes and Boss-aligned run boundaries; 03 — Project route-horizon safety and erosion recoverability; 04 — Enforce Code-family integrity and hard eligibility; 05 — Simulate native buff timelines and parameter value; 06 — Value crest, charge, stack, erosion, and Force Chain mechanics.

**Status:** ready-for-agent

- [ ] The decision pipeline applies hard eligibility before Equipment Combat Tier Order.
- [ ] Survival-repairing rear/full-party value leads only while an authoritative survival deficit exists.
- [ ] Otherwise the order is back-row Force Chain payoff, rear/full-party offense, nonessential rear/full-party defense, then front-only fallback.
- [ ] A proven party-global resource triggered by a front-row match keeps its global value without weakening Rear-Row Priority generally.
- [ ] Coverage, native magnitude, trigger behavior, and repeatable Boss value break ties only inside the same tier.
- [ ] Zero- or negative-marginal candidates consume Equipment rerolls only above the configured reserve and are otherwise declined even below capacity.
- [ ] At capacity, every possible retained portfolio is evaluated and replacement requires a strict complete-portfolio improvement.
- [ ] Opposed-family contamination and hard-excluded held Codes are preferred removal targets without accepting a non-improving new portfolio.
- [ ] A direct Offer at capacity may end in selection, replacement, reroll, or decline; decline closes the Offer without rollback.
- [ ] Unknown evidence excludes only its candidate, and the Offer pauses only after all candidates and permitted rerolls are exhausted.
- [ ] End-to-end policy tests assert stable tie breaking, exact replacement identity, reroll reserve, decline, and no displayed-power fallback.
