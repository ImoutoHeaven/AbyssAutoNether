# Triage Labels

Use this one-to-one readiness vocabulary for GitHub Issues:

- `needs-triage`: the request has not been classified or verified.
- `needs-info`: implementation is blocked on missing stakeholder information.
- `ready-for-agent`: the issue is sufficiently specified for an implementation agent.
- `ready-for-human`: the next required action must be performed or decided by a person.
- `wontfix`: the request was deliberately declined.
